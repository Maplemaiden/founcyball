# Founcyball MVP 设计文档

> 足球主题 · 俯视 2D · 双人回合制弹球对战

**版本：** 0.1（MVP）  
**目标：** 验证核心手感——力度/弧度击打、圆形碰撞反弹、滑动摩擦、边线反弹，以及「各控 3 人」的回合对战节奏。

---

## 1. 一句话定位

两人轮流操控各自 3 名圆形球员，用「力度 + 弧度」击打球员或足球，借助物理滑动与反弹，把球打进对方球门得分。

---

## 2. MVP 范围

### 2.1 做（In Scope）

| 模块 | 内容 |
|------|------|
| 对局 | 本地双人，同一设备轮流操作 |
| 单位 | 每方 3 名圆形球员 + 1 个圆形足球 |
| 操作 | 选球员 → 调力度 → 调弧度 → 发射 |
| 物理 | 弹性碰撞（球-球、球-人、人-人）、滑动摩擦、球场边缘反弹 |
| 胜负 | 球进门得分；先到 N 分或限时结束 |
| 场地 | 矩形球场 + 两端球门 + 中线/中圈（示意即可） |

### 2.2 不做（Out of Scope）

- 联网对战、AI 对手
- 技能、道具、特殊球员数值差异（MVP 全员同属性）
- 复杂动画/粒子特效
- 换人、犯规、越位等足球规则
- 音效曲库、完整 UI 皮肤系统
- 录像回放、成就系统

---

## 3. 核心循环

```
选中我方球员
    ↓
阶段 A：控制力度（蓄力/拉条）
    ↓
阶段 B：控制弧度（瞄准方向 + 可选曲线）
    ↓
确认击打 → 该球员获得初速度（可带角速度/侧向分力）
    ↓
物理模拟：全场物体滑动、碰撞、边线反弹，直到全部静止
    ↓
若进球 → 计分 → 重置开球位
若未进球 → 换对手回合
    ↓
重复，直到胜负条件满足
```

**关键约束：** 只有「当前回合方」的球员可被选中并击打；足球与双方球员均可被击中产生连锁反应。

---

## 4. 操作设计

### 4.1 输入流程（两段式）

玩家**不会**在同一帧同时调力度与弧度，而是严格两段：

1. **力度阶段**  
   - 选中球员后进入蓄力。  
   - 输入：按住并拖动距离 / 或进度条来回扫（二选一实现，推荐**拖拽距离映射力度**）。  
   - 范围：`0 ~ MaxPower`，UI 显示力度条。  
   - 确认后锁定力度，进入弧度阶段。

2. **弧度阶段**  
   - 调节出射方向（瞄准线）。  
   - 「弧度」= 给击打附加侧向分量或初始角速度，使轨迹略带曲线/旋转效果。  
   - MVP 简化：弧度滑条 `-1 ~ +1`，映射为垂直于瞄准方向的侧向初速度比例，或角速度。  
   - 确认后发射，进入物理结算。

### 4.2 可击打对象

| 对象 | 玩家能否直接选中击打 | 能否被碰撞推动 |
|------|----------------------|----------------|
| 我方球员 | 是（仅当前回合） | 是 |
| 对方球员 | 否 | 是 |
| 足球 | 否（间接推动） | 是 |

> MVP 不开放「直接选中足球击打」，保持「用球员踢球」的足球感；连锁碰撞可推动任意圆形物体。

### 4.3 取消与重选

- 力度/弧度阶段允许取消，回到选人。  
- 物理进行中不可操作。

## 5. 单位与场地

### 5.1 圆形单位

| 类型 | 数量 | 半径（建议相对值） | 质量 | 弹性 | 摩擦 |
|------|------|-------------------|------|------|------|
| 球员 | 每方 3 | 1.0 | 1.0 | 0.75 | 中 |
| 足球 | 1 | 0.55 | 0.35 | 0.85 | 低（滑更远） |

- 全员圆形，俯视无朝向依赖（弧度用侧向力表现即可）。  
- MVP：**同队球员属性完全相同**。

### 5.2 球场

- **尺度**：按 FIFA 常用标准 **长 105m × 宽 68m**，门宽 **7.32m**；禁区/球门区/中圈用标准示意尺寸。  
- **朝向（手机竖屏）**：球场**竖置**——长度沿屏幕纵向，球门在**上/下两端**；宽度为屏幕横向。逻辑坐标勿拉成正方形。  
- 四周为**硬边界**（速度法线分量翻转 × 边线弹性系数）；球门开口对足球开放。  
- 球门柱：短碰撞体，避免「贴边穿门」。

### 5.3 初始站位（示意）

```
┌──────────── Goal A ────────────┐
│  A1        A2        A3        │
│                                │
│              ● Ball            │
│                                │
│  B1        B2        B3        │
└──────────── Goal B ────────────┘
```

- 开球：球放中圈；进球后球回中圈，球员回初始位（MVP 最简单）或仅球回中、球员原地（二选一，推荐**全重置**保证公平）。

## 6. 物理规则（MVP）

### 6.1 运动模型

- 俯视 2D，无重力。  
- 速度积分：`v *= (1 - drag * dt)`（线性阻尼模拟草地滑动）。  
- 当 `|v| < RestThreshold` → 置零。  
- **全场所有物体 `|v|` 均低于阈值且持续若干帧** → 回合物理结束。

### 6.2 碰撞

- **圆-圆：** 弹性（或半弹性）分离；沿碰撞法线交换冲量；可选少量切向摩擦。  
- **圆-边：** 法线速度反向 × `wallBounce`（建议 `0.85~0.95`）。  
- 穿透修正：位置沿法线推出重叠。

### 6.3 击打初速度

```
forward = aimDir * power
side    = perp(aimDir) * power * curveFactor * curveInput   // curveInput ∈ [-1,1]
v0      = forward + side
```

可选：同时给 `angularVelocity = curveInput * k`，仅影响表现或轻微切向碰撞（有精力再做）。

### 6.4 调参目标（手感）

- 单次中等力度：球滚动约半场到 2/3 场。  
- 大力撞墙：明显减速但仍有回弹。  
- 三人连环撞击不应爆炸式加速（限制最大速度 `vMax`）。

## 7. 回合与胜负

### 7.1 回合

1. 先手：可抛硬币 / 固定 Player A。  
2. 当前玩家：选人 → 力度 → 弧度 → 发射。  
3. 等待静止 → 判定进球 → 否则换边。  
4. **同一回合只允许击打一次**（不可连击）。

### 7.2 进球

- 球整体越过对方门线 → 当前造成进球的一方得分（与「谁踢的最后一脚」无关，**谁推进去算谁的**——MVP 采用「球进哪边门，对面得分」即标准攻防：球进 A 门则 B 得分）。  
- 进球后：比分 +1，短暂提示，重置站位，由**失球方**开球（或进球方继续，选一种写死：**失球方开球**）。

### 7.3 胜负条件（任选其一写入配置）

- **先到 3 分获胜**（推荐 MVP），或  
- **限时 3 分钟，分高者胜；平局加时一球决胜 / 判平**。

MVP 推荐：**先到 3 分**，实现最简单。

### 7.4 僵局（可选极简）

- 连续 N 回合双方都未进球且无明显推进：提示可重置球位（非必须，可后置）。

## 8. 界面与反馈（最小）

### 8.1 对局 HUD

- 双方比分  
- 当前回合指示（高亮可控球员）  
- 阶段提示：选人 / 力度 / 弧度 / 等待静止  
- 力度条、弧度条（或拖拽辅助线）  
- 瞄准线（从球员指向出射方向）

### 8.2 反馈

- 选中圈、蓄力时圆放大/颜色变化  
- 进球：简短文字「GOAL」+ 停顿  
- 物理结束：轻微提示轮到对方  

### 8.3 场景外

- 标题：开始游戏  
- 结束：胜负结果 + 再来一局

## 9. 技术建议（非绑定）

| 项 | 建议 |
|----|------|
| 引擎 | Godot 4 / Unity 2D / Phaser / 自研 Canvas 均可 |
| 物理 | 可用引擎 2D 物理，或自写圆碰撞 + 欧拉积分 |
| 分辨率 | 逻辑坐标与屏幕解耦；固定逻辑球场尺寸 |
| 帧率 | 物理用固定步长（如 60Hz）避免不同机器手感差 |

**建议核心类/模块：**

- `Match`：回合、比分、阶段状态机  
- `Pitch`：边界、球门判定  
- `Body`：圆、位置、速度、质量  
- `PhysicsWorld`：积分、碰撞、休眠检测  
- `InputController`：选人、力度、弧度两段输入  
- `UI`：HUD / 结算  

**状态机：**

```
Menu → Kickoff → SelectPlayer → AimPower → AimCurve → Simulating → CheckGoal
         ↑                                              ↓
         ←─────────── GoalReset / SwitchTurn ←──────────┘
                              ↓
                         MatchOver
```

## 10. 验收标准（MVP Done）

- [ ] 本地双人可完整打完一局（先到 3 分）  
- [ ] 每方 3 圆形球员 + 1 球，俯视可见  
- [ ] 回合制：选人 → 力度 → 弧度 → 发射，一次一击  
- [ ] 击打后球员/球滑动，互相碰撞反弹，撞边反弹  
- [ ] 全部停下后才切换回合  
- [ ] 球进门正确计分并重置  
- [ ] 力度明显影响滚动距离；弧度明显影响出射偏向  
- [ ] 不可在对方回合操控对方球员  

---

## 11. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 物理抖动/穿透 | 固定时间步 + 位置修正；限制 vMax |
| 永远不停 | 休眠阈值 + 最大模拟时长强制结束 |
| 弧度难理解 | 瞄准线旁显示弯曲预览点（虚线采样） |
| 球卡门柱 | 门柱独立碰撞；进球判定用门线段 |

---

## 13. 术语表

| 术语 | 含义 |
|------|------|
| 力度 | 击打初速度大小 |
| 弧度 | 垂直瞄准方向的侧向分量或旋转，使轨迹非纯直线 |
| 休眠 | 速度低于阈值视为静止 |
| 连锁 | 击打后多物体连续碰撞 |

---

**文档结论：** MVP 只服务一件事——让两人在同一块俯视球场上，用「力度 + 弧度」轮流弹击圆形球员，打出可信的滑动与反弹，并把球推进球门。其它内容一律后置。
